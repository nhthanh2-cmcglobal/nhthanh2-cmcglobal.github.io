Privacy Policy — API Auto Test Studio

Last updated: 2026-11-23

API Auto Test Studio is a browser extension that runs RESTful API and JSON-RPC 2.0 test cases that you import from Excel files.

Data we collect

None. The extension has no server, no analytics, no telemetry, no advertising and no account system. The developer does not receive any of your data.

Data stored on your device

The following is stored locally in your browser only, and never transmitted to the developer:

  • Test suites, imported Excel content and API responses (IndexedDB).
  • Project settings such as Base URL, endpoint mapping, environment profiles and non-secret headers/variables (localStorage, chrome.storage.local).
  • Secrets (tokens, passwords, API keys, cookies) are removed before settings are persisted. Session tokens are kept in chrome.storage.session, which is cleared when the browser closes. Role secrets are written to disk only if you explicitly enable "remember" for that role.

You can delete everything by removing the extension or clearing its site data.

Network requests

The extension sends HTTP requests only to the servers you configure as test targets, and only when you run a test. Cookies are not sent unless you enable "include credentials". No request is made to the developer or to any third party. All code is bundled; no remote code is loaded.

Permissions

  • storage — save your settings and test suites locally.
  • activeTab — read the origin (scheme + host) of the current tab when you click "Get Base URL from current tab" in the popup. Page content is never read.
  • Optional host permissions (http://*/*, https://*/*) — requested per origin, at run time, only for the API servers you choose to test. You can revoke them anytime in chrome://extensions.

Children

The extension is a developer tool and is not directed at children.

Changes

Changes to this policy will be published with the new extension version.

Contact
